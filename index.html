동영상 목록

    아이폰에서 PiP로 보는 방법
    1. 영상을 재생합니다.
    2. 플레이어 오른쪽 아래의 전체화면 버튼을 누릅니다.
    3. 전체화면 왼쪽 위의 PiP 버튼을 누르거나, 홈 화면으로 쓸어 올립니다.

    설정 → 일반 → 화면 속 화면에서 "자동으로 PIP 시작"이 켜져 있어야 합니다. 영상에 따라 유튜브가 PiP를 막을 수 있습니다.

    PiP 버튼 사용 조건 (Safari 확장 필요)

    유튜브 영상은 다른 사이트(youtube.com)의 iframe 안에 있어서 이 페이지만으로는 PiP를 켤 수 없습니다. "YT PiP 도우미"(유저스크립트 또는 Safari 확장)를 설치하면 PiP 버튼이 iframe 안의 영상에 직접 PiP를 요청합니다.

    1. Mac 없이: App Store의 무료 앱 "Userscripts"를 설치하고, 설정 → (앱 →) Safari → 확장 프로그램에서 Userscripts를 켜고 youtube.com 접근을 허용합니다. Safari에서 ytpip-helper.user.js를 열어 설치합니다.
    2. 또는 Mac의 Xcode로 확장 앱을 빌드해 설치하고, 같은 설정 화면에서 "YT PiP 도우미"를 켭니다. (저장소의 safari-extension/README.md)
    3. 영상을 재생한 뒤 PiP 버튼을 누릅니다. 거부되면 영상 화면을 한 번 탭하고 바로 다시 누릅니다. 확장 앱을 설치했다면 주소창의 페이지 메뉴에 있는 확장 목록에서 "YT PiP 도우미"를 눌러도 됩니다.

    확장 연결 상태: 감지되지 않음
